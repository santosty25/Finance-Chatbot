# Introduction
This is my project, a personal finance app made using next.js, JavaScript, and PostgreSQL. The app allows the user to enter their income, expenses, and budgets and receive financial advice using LLMs.

# Tech Stack
* Next.js
* JavaScript
* OpenAI API
* Tailwind CSS
* PostgreSQL
